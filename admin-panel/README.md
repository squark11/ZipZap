# ZipZap — Admin Panel (Angular)

Panel webowy dla ról **STORE_EMPLOYEE**, **DRIVER**, **ADMIN**
(kompletacja zamówień, zarządzanie ofertą, przypisania dostaw, administracja).

> **Status: szkielet powstaje w etapie 5** (po modułach Identity, Catalog, Ordering).
> Na start: logowanie + lista zamówień sklepu jako dowód integracji z API.

Stack docelowy: Angular 17+ (standalone components), konsumpcja ZipZap.Api (JWT).
Kolory/typografia: z `/branding`.

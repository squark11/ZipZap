# ZipZap — Marka

Zasoby marki dla wszystkich aplikacji (backend admin, panel Angular, mobile Flutter).

## Logo
- `zipzap-logo-carrot.svg` — abstrakcyjna marchewka (świeżość/lokalność) + wordmark „ZipZap".
- Format wektorowy (SVG) — skaluje się bez utraty jakości.

## Kolory
| Rola       | HEX       | Token CSS         |
|------------|-----------|-------------------|
| Primary    | `#F97316` | `--zz-orange`     |
| Secondary  | `#22C55E` | `--zz-green`      |
| Grafit     | `#3A3F4B` | `--zz-graphite`   |

Pełna paleta (warianty, statusy, radiusy, cienie): [`palette.css`](palette.css).

## Typografia
Zob. [`typography.md`](typography.md) — Poppins (nagłówki) + Inter (UI).

## Zasady użycia
- Zachowaj kontrast (WCAG AA): grafit na białym/jasnym tle; pomarańcz jako akcent akcji.
- Zielony rezerwuj dla „świeżości", potwierdzeń i statusów dostawy.
- Minimalny margines ochronny logo = wysokość litery „Z" wordmarku.
- Nie zmieniaj kolorów logo ani proporcji.
